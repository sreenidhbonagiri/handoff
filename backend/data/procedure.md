# Sample closeout procedure

This is a sample demonstration procedure written for the Handoff prototype. It is not manufacturer guidance and does not describe how to safely service any equipment.

## 1. Asset ID confirmed
Record the asset identifier printed on the unit's label.

## 2. Completed action and parts/quantity recorded
Record each action performed. For replaced parts, record the part and the quantity.

## 3. Final functional-test result recorded
Record whether the final functional test was performed and its result (passed or failed). A planned test is not a result.

## 4. Remaining issue status recorded
For every reported problem, record whether it remains or was resolved. If no problems remain, say so explicitly.

## 5. Follow-up recorded when an issue remains
If any problem remains unresolved, record the planned follow-up (visit, ticket, or work order).
